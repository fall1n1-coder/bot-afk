# AFK-бот для Minecraft 26.2 (mineflayer) — деплой на Render

## Что делает

- Подключается к серверу на протоколе Minecraft 26.2 и поддерживает соединение.
- Каждые ~7–45 сек выполняет случайные действия (прыжок, поворот камеры,
  шаг вперёд/назад, взмах рукой), чтобы не триггерить анти-афк системы сервера.
- Автоматически переподключается при кике/дисконнекте.
- Поднимает мини HTTP-сервер (обязателен для Render Web Service).

## Как реально устроена поддержка версии 26.2 (проверено вручную)

На связке `mineflayer@4.37.1` + `minecraft-data@3.113.1` (та, что подтягивается
по умолчанию) выяснено следующее:

1. **`minecraft-data` уже прекрасно знает про 26.2.** В
   `pc/common/protocolVersions.json` есть запись
   `{ minecraftVersion: "26.2", version: 776, majorVersion: "26.1" }` —
   то есть протокол-номер (776) правильный, а блоки/предметы/структуры пакетов
   берутся из уже существующей папки данных `26.1`. `mcData('26.2')`
   резолвится без ошибок из коробки — патчить `minecraft-data` не нужно.

2. **Настоящая причина отказа — сам mineflayer.** В файле
   `node_modules/mineflayer/lib/version.js` жёстко зашит список
   `testedVersions`, заканчивающийся на `'1.21.11'`. Если версия сервера
   "новее" этого списка (а 26.1/26.2 новее), mineflayer выбрасывает:
   ```
   Error: Server version '26.1' is not supported. Latest supported version is '1.21.11'.
   ```
   Это и есть настоящий блокер — не `ETIMEDOUT`, не сетевые проблемы, а
   ранняя синхронная проверка версии при создании бота.

3. **Патч (`scripts/patch-26.2.js`)** дописывает `'26.1'` в конец
   `testedVersions` внутри установленного пакета `mineflayer`. После этого
   `createBot({ version: '26.2', ... })` спокойно проходит проверку версии и
   переходит к реальному TCP-подключению. Проверено вручную: до патча —
   синхронная ошибка `is not supported`; после патча — бот доходит до
   сетевого уровня и ждёт ответа сервера.
4. Патч запускается автоматически через `postinstall` в `package.json`,
   то есть срабатывает при каждом `npm install` (в том числе на Render при
   каждом деплое), и идемпотентен — повторные запуски ничего не портят.

**Ограничение:** новые блоки/предметы, добавленные именно в 26.2 (например
Cinnabar Block Set), физически отсутствуют в данных — используется набор
блоков/предметов от 26.1. Для anti-afk бота (ходьба, прыжки, осмотр, чат,
respawn, реконнект) это не критично.

## Установка локально

```bash
npm install   # автоматически запустит патч через postinstall
MC_HOST=Czyninski.aternos.me MC_USERNAME=MyBot npm start
```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `MC_HOST` | да | Адрес сервера, например `Czyninski.aternos.me` |
| `MC_PORT` | нет | Порт (по умолчанию 25565) |
| `MC_USERNAME` | да | Имя бота в игре |
| `MC_VERSION` | нет | По умолчанию `26.2`. Переопредели, если нужно подключаться к другой версии |
| `RECONNECT_DELAY_MS` | нет | Задержка перед реконнектом (по умолчанию 15000) |
| `PORT` | нет, задаёт Render сам | Порт для HTTP-сервера |

## Деплой на Render

1. Залей эти файлы в свой репозиторий (`fall1n1-coder/bot-afk`).
2. Render → New → Web Service → подключи репозиторий.
3. Build Command: `npm install` (запустит и `postinstall` с патчем)
4. Start Command: `npm start`
5. В Environment добавь переменные из таблицы выше.
6. **Free план усыпляет Web Service после ~15 мин без HTTP-запросов.** Для
   настоящего 24/7 либо переходи на платный план, либо настрой внешний пинг
   (UptimeRobot / cron-job.org) на корневой URL сервиса каждые 5–10 минут.

## Важно про Aternos + Render (твой блокер: ETIMEDOUT)

Это отдельная от версии 26.2 проблема. Aternos активно блокирует подключения
с известных диапазонов IP облачных хостинг-провайдеров (Render, Railway,
Heroku и т.д.), так как боты для искусственного поддержания сервера прямо
запрещены их правилами. `ETIMEDOUT` именно к Aternos с облачного хостинга —
типичный симптом такой блокировки, а не проблема кода бота или версии.

Что можно проверить:
- Подключиться к тому же серверу тем же кодом с обычного домашнего IP —
  если работает, дело действительно в IP Render.
- Учитывать, что даже при удачном обходе блокировки такой бот нарушает
  правила Aternos, и сервер/аккаунт могут забанить.
